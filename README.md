## How I work

1. **Land it.** Bring raw data in as it arrives (Bronze).
2. **Clean it.** Fix types, duplicates and gaps, and conform the data (Silver).
3. **Model it.** Shape it into tables the business can use (Gold).
4. **Test it.** Check every run, so bad data is caught before anyone sees it.
5. **Show it.** Put the result in a dashboard people can read without an analyst.
